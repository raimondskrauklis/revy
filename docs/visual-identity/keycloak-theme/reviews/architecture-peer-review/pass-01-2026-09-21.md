Since the plan drops parent `styles.css` (correct per findings), it's unclear whether `stylesCommon` is still inherited or also replaced. The plan needs to resolve this: either create `keycloak/themes/` as a new path or use the absolute bind-mount `/mnt/revy_volume/keycloak-themes:/opt/keycloak/themes:ro`. |

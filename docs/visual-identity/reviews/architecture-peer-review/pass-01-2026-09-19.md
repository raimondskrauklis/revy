## Design judgment (advice — not a lock)

**Keep:** PR operator console as *job*, not as CRT theme. Two intensities. Thin public costume. Rebuild in-app UX. Plex pair for reading (Sans) + chrome (Mono). Wordmark-first. Token overlay. No scanlines, no `#00FF00` body, no 3-card landing, no paint-only.

**Change before planning:** the thing you would still notice with the wordmark covered should be **density and lamps**, not mint type on black.

Concrete recipe (advice to encode in findings, then general plan):

1. **Canvas** — near-black with a *green or warm olive cast*, not GitHub `#0d1117` and not Greptile `#2A2A2A` + `#28E99F`. Gloam’s P1 phosphor notes are the readable version of this idea: background `#040804`, body `#C0E8B8`, bright green only for cursor/accent ([phosphor.md](https://github.com/marvinrichter/gloam/blob/main/themes/phosphor/phosphor.md)). Warp’s lesson stands: warmth/undertone is more distinctive than neon ([Warp DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/warp/DESIGN.md)).
2. **Body vs accent** — dim olive / warm off-white for reading. Phosphor green for wordmark, prompt, primary CTA, live status. Amber/red for warning/danger lamps. Success green for merge-ready only.
3. **Type** — IBM Plex Sans + Mono, latin-ext, self-host OFL. Public *may* be mono-led on the wordmark/hero; do **not** copy IBM “undertyping” or prompt-prefixed headlines ([IBM Developer typography](https://www.ibm.com/brand/experience-guides/developer/brand/typography/)). Carbon’s productive vs expressive split is a better model for VI-Q1 B than “terminal landing.”
4. **Mark** — `revy` in Plex Mono. Favicon = custom wedge/lamp geometry at 16px. Never `>` as the asset.
5. **Chrome** — 0–4px radius, hairline not `ring-1` cards, ~28–32px rows (Datadog/Linear operator density), tabular numbers, Lucide OK in-app until a glyph set exists, Lucide **not** the landing identity.
6. **IA** — default authenticated route toward reviewer; dashboard is status + connect + next action, not hello-{name}; no fake stats (principle 2).
7. **Motion** — 120–200ms, snap/opacity on chrome only; reduced-motion already global. Public cursor blink dies with that media query (VI-Q3).

**What not to copy:**

- Greptile: mint + Space Mono + “bugs as glitch.” Too close in category.
- designmd Terminal Green / CRT CLI templates: `#0d1117` + `#39d353` + JetBrains + scanlines.
- IBM Developer: Plex Mono Light + glyph headlines + undertyping.
- Warp/Linear: steal *restraint and density*, not their orange/warm-charcoal (those are their marks).
- CodeRabbit: dark + huge white CTAs + orange — fine as “not us,” not a source.

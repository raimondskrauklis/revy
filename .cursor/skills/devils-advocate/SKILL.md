# Devil's Advocate

1. Read the plan/doc (and any referenced files).
2. Assume it's wrong — attack assumptions, ordering, scope, estimates, and what's silently omitted.
3. Report: **gaps, inconsistencies, corners cut, things to improve** — prioritize by impact.
4. **Questions:** only to resolve genuine ambiguity; no generic suggestions.
5. Stay proportional: short plan → short answer; large plan → structured sections.

**Invoke with:** "Zoom out, devil's advocate mode. Find gaps, inconsistencies, corners cut, and things to improve."
